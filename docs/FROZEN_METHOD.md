# 冻结方法说明

## 身份信息

- 方法名称：TBM PLC 四阶段施工过程分析
- 版本：`tbm_four_phase_v1_2026-10-12`
- 状态：`frozen`
- 冻结日期：2026-10-12
- 数据质量版本：`tbm_plc_quality_v1_2026-10-12`
- 软件架构版本：`tbm_process_layered_v1_2026-10-13`
- 参数文件：`config.json`
- 配置与核心源码校验值：每次正式运行写入 `outputs_frozen_v1/method_manifest.json`

软件架构版本只记录代码分层与接口组织。四阶段方法名称、阈值、判据和研究结论仍使用原冻结版本。

研究人员对10天样本曲线进行了目视合理性检查，未发现明显不合理分段。

上述记录是目视合理性检查，不是人工真值标注，不代表 100% 准确率。

## 输入和层级

运行状态层由原始 `掘进状态`、质量受控推进速度、推力、扭矩和暂定统一刀盘转速共同形成。`raw_state=0` 时归入停止状态；`raw_state!=0` 时再区分推进、空转、无推进推压和待机等状态。

掘进循环内部只使用四个阶段标签：

1. `startup`
2. `rising`
3. `stable`
4. `declining`

无法可靠识别稳定阶段时，不强制生成四阶段。动态分析继续在 `unsegmented_cycle` 或 `unidentified_process` 范围运行。

## 阶段识别字段

主要三参数为：

- 推力 `thrust`
- 刀盘扭矩 `torque`
- 质量受控贯入度 `penetration_analysis`

当贯入度不可用时，允许使用质量受控推进速度作为回退信号。时间、原始掘进状态、推进速度、刀盘转速和里程用于状态、边界、质量或追溯，不替代三参数稳定性投票。

## 冻结核心规则

- 稳定窗口：180 秒，至少 5 个样本。
- 稳定段：至少 180 秒且至少 8 个样本。
- 三参数平稳性：归一化标准差不高于 0.10，分钟斜率绝对值不高于 0.04。
- 平稳投票：三参数中至少 2 个满足，且活动水平不低于 0.35。
- 稳定占用率窗口：300 秒，最低占用率 0.50。
- 稳定候选连接：允许连接不超过 300 秒、仍满足推进约束的内部间隔。
- Score-Kneedle：用于边界候选与评分，不单独决定稳定阶段。
- `startup` 与 `rising`：依据加载水平、持续时间和多参数方向证据区分。
- `declining`：依据末端多参数下降、原始状态切换和有限终止上下文识别。
- 硬采样缺口：大于 180 秒时切断连续性，不能被循环、阶段或动态窗口跨越。

完整数值以 `config.json` 和正式输出的 `method_manifest.json` 为准。本文件不取代机器可读配置。

## 归属规则

相邻循环可共享上下文记录用于边界判断，但正式输出按确定顺序统一结算：每条原始记录最多属于一个循环、一个阶段和一个动态分析范围。阶段汇总在最终归属完成后由逐点记录重新计算。

## 数据质量口径

- 原始字段永远保留。
- 极端或缺失推进速度不进入速度统计和状态分析，不使用给定速度冒充实际速度。
- 与不可信速度关联的原始贯入度不进入阶段分析；有可靠参考值时可明确标记后使用参考贯入度。
- 刀盘转速统一映射仍是待点位表确认的暂定口径，不能写成已确认 PLC 事实。
- 硬缺口没有观测证据，因此不计为运行或停机时长。

## 适用限制

- 约 20 秒采样无法稳定拆分非常短的空转、空推和快速过渡。
- 并非每个循环都必须出现完整四阶段。
- 参数趋势和共同变化是机器响应事实，不提供地质或故障诊断。
- 尚未完成基于正式人工标注的定量准确率验证。
