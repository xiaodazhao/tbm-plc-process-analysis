# 当前施工日报事实验证器

## 目的

当前验证器用于A-E日报生成后的独立确定性核验，并为E组提供一次局部修订依据。它不读取原始PLC，不修改平台或四阶段结果。

## 当前能力

- 中文 `米` 与 `m` 均按“今日进尺/导向盾首里程”的明确字段角色核验。
- 先按句号、分号和括号外逗号拆分独立主张，再逐项核验；同一参数的数值续写、波动描述及质量记录数会保留主语上下文。
- PASS必须至少完成一项类型化字段角色核查；只匹配事实编号、关键词或无类型数值不能PASS。
- 未覆盖、部分覆盖、错误事实编号和无法确定性裁决的内容进入REVIEW。
- 总跨度、累计活动时长、状态时长、间隔时长、响应持续时间分别核验。
- 质量事件数、受影响PLC记录数、事件跨度记录数分别核验。
- 秒级原值采用1秒绝对容差；按分钟或小时概括时采用60秒显示容差；百分数按报告显示的小数位允许正常四舍五入。
- D到E另外计算事实编号、已核查角色和数值角色保留率，防止删除信息后只看通过率。

## 输出指标

- `deterministic_numeric_check_pass_rate`：明确执行的数值角色检查中PASS占比。
- `required_fact_verified_coverage`：既有必需事实中被明确核查、且没有FAIL或REVIEW污染的比例。
- `fully_verified_claim_rate`：非N/A独立主张中PASS占比。
- `explicit_failure_rate`：明确FAIL主张及全局FAIL检查占比。
- `review_rate`：需要人工复核的主张占比。
- `deterministic_decision_rate`：PASS或FAIL的确定性裁决占比。

上述都是规则验证器内部指标，不能称为实际工程事实准确率。

固定回归集同时报告正向用例误拒绝率和错误注入漏检率。这两个比例只描述列出的回归样本，不代表验证器在任意施工日报上的总体准确率。

## 运行

```bash
conda run -n LLMenv python -m pytest -q tests/test_llm_report_verifier.py
```

验证结果随A-E实验保存在`outputs/llm_experiment/`。当前仓库不再保留旧验证器或历史重评价输出。
