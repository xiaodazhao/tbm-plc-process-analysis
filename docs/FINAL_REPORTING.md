# TBM 施工日报最终候选版方法

## 1. 方法边界

最终候选版位于冻结 PLC 分析和地质 V2 r5 之后，是一个独立、确定性的事实呈现与审计层。它不重新计算原始 PLC，不改变运行平台、四阶段、进尺质量或动态事件，也不重新提取地质 PDF、不改写 V2 内容计划。

输入分为两类：

1. PLC 冻结结果：每日逐点结果、运行平台、阶段、动态事件和完整结构化 JSON。
2. 地质 V2 r5 结果：内容单元、必选/可选属性、内容计划、来源文件、页码及证据映射。

输出为三章 A4 PDF、地质里程轴、逐日结构化事实、内容单元展示映射和独立成品审计。

## 2. 完整处理流程

1. 读取冻结 PLC 每日结果，构建第一、二章事实。
2. 读取 V2 r5 已通过检查的内容单元和内容计划。
3. 将选中地质内容单元转换为 TSP/HSP 预测分段、风险点或风险区间、历史素描点。
4. 使用完整 DyK 里程换算后的数值坐标绘制地质里程轴。
5. 由确定性规则构建第三章关键地质信息和来源列表。
6. 将三章事实、时间轴、PLC 曲线和地质轴装入固定 HTML/CSS 模板。
7. 通过 Chrome 以 A4 纵向输出 PDF。
8. 独立审计器重新读取 JSON、PDF 和逐页 PNG，检查事实映射、来源、图形和页面。

## 3. 第一章与第二章

第一章沿用冻结口径：日进尺只取导向盾首里程当日有效首末差；工作和停机时长按既有状态分类及封顶采样间隔累计；硬缺口不并入工作或停机。参数统计只使用既有运行平台内的非停止记录，并继续应用冻结的数据质量标记。

第二章完整保留既有平台优先运行区间，不把自动区间称为人工确认的掘进循环。区间进尺来自“开累进尺”的既有质量判断，只用于区间记录。主要施工变化从冻结动态事件中筛选，并在原事件时间和行号范围内复算首、末四分之一有效样本中位数。变化量是原始记录值差，不是百分比、阈值或原因诊断。

PLC 点位表尚未取得，主要参数的工程单位不作猜测；报告明确标记为原始 PLC 记录值。

## 4. 地质里程轴

### 4.1 坐标

`DyK1015+819`转换为完整数值`1015819.0 m`参与计算，不使用`+819`局部值。显示窗口综合当日导向盾首范围、有效预测分段、风险和历史观察位置确定。若以后启用裁剪，模型与审计必须显式记录未显示范围，禁止静默丢弃。

### 4.2 三条轨道

- TSP 轨道：显示原报告预测分段和建议围岩等级。
- HSP 轨道：独立显示原报告预测分段和建议围岩等级。
- 历史素描轨道：只显示真实观察位置的单点，不向前后范围外推。

当 TSP 与 HSP 对同一范围的等级不同，两条色带并列保留，不作平均或择一。围岩等级统一映射为绿色、黄橙色、暗红色等颜色；颜色仅表示原报告等级，不表示综合风险。

### 4.3 风险几何

风险独立于围岩色带。原记录是点位时绘制点符号，原记录是区间时绘制区间线；不得把区间端点解释为两个风险点。相同来源类型、位置、风险类型和几何的重复项可合并展示，但保留全部内容单元和来源编号。

### 4.4 当日位置

导向盾首起点和终点使用两条虚线标出，中间淡色区域仅表示当日导向盾首里程范围。零进尺时起止位置重合并明确标记。该范围不等同于已确认掌子面范围。

## 5. 第三章压缩规则

第三章固定为：A. 地质信息里程轴；B. 关键地质信息；C. 原始资料来源。

图上只保留等级、里程、风险符号、来源短编号和当日位置。文字表只补充图形不能完整表达的内容：TSP/HSP 等级差异、原文明确的断层破碎带或水文预测、风险几何、历史单点观察和上游待核实项。连续且来源、等级组合相同的差异范围合并表达，不删除其内容单元映射。

每个选中内容单元都必须映射到至少一种展示元素：预测色带、风险符号、历史观察点或关键地质信息。来源列表继续保留原文件名、可靠页码和可用日期依据。

## 6. 程序与 LLM 分工

V2 r5 上游曾使用 LLM 生成内容计划、第三章原子陈述、辅助语义复核及局部修正，确定性程序承担时空匹配、内容单元、必选义务、硬门禁和信息保留检查。本最终呈现层只消费已经完成的 V2 计划与证据，不新增规划或文本生成，不调用 LLM。

地质坐标、色带、风险几何、表格、来源索引、HTML/PDF 以及全部审计均由确定性程序生成。

## 7. 自动审计

独立审计器检查：

- 所有选中和必选内容单元都有结构化展示映射；
- 完整里程、分段长度、等级颜色、风险点/区间和历史观察点一致；
- 来源文件与报告 ID 存在，页码只接受正整数或空值；
- 上游待核实项仍保留处理说明；
- PDF 可读取、A4 纵向、每页有可提取文本、三类图像已嵌入；
- PDF 实际包含全部来源编号和第三章三个组成部分；
- PNG 页面数与 PDF 一致，页面不存在异常大面积空白；
- 地质轴标注无已检测重叠，绘图范围没有静默裁剪。

全部 PDF 另以逐页 PNG 联系图进行人工版式检查。自动和目视检查均不替代工程专家对原始资料的独立评价。
