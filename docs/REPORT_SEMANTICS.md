# 工程语义与日报定量层

`tbm_process/reporting/`位于当前PLC分析和LLM之间，只读取结构化结果，不修改平台、四阶段或动态事件边界。

## 工程语义

`semantics.py`完成：

1. 提取当日概况、主要过程、运行响应和数据质量事实；
2. 按透明规则组织代表性过程和可比较时段；
3. 生成确定性中文事实表达；
4. 保留源文件、原始行号、统计口径和质量限制。

算法平台不会直接翻译成现场确认的“真实掘进循环”。间歇活动必须保留累计活动时长和中间间隔，不能写成整段连续掘进。

## 日报量化

`quantitative.py`根据完整事实、逐点结果和工程语义生成：

- 当日进尺、状态时长及占比；
- 推进状态下的参数统计；
- 主要施工过程参数统计；
- 运行响应的初末值、变化量和百分比；
- 数据质量事件数与受影响记录数；
- 正式模式和研究预览模式的LLM输入。

今日进尺只采用导向盾首里程首末差。工程单位未确认的参数在正式模式下不发布绝对数值；研究预览必须明确标注“原始PLC记录值，工程单位待核实”。

## 当前执行方式

工程语义和量化事实已经纳入唯一入口：

```bash
conda run -n LLMenv python scripts/run_current_analysis.py
```

输出位于`outputs/current_analysis/construction_semantics/`、`quantitative/`和`llm_inputs/`。仓库不再保留旧的独立构建脚本和旧输出目录。
