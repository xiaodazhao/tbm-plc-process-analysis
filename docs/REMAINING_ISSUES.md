# 剩余问题

以下仅列当前真实未解决事项。

1. **尚无正式定量准确率。** 10 天结果做过研究人员目视合理性检查，但还没有逐点人工真值，因此不能计算阶段准确率、召回率或边界误差。
2. **刀盘转速映射仍待确认。** 现有统一转速字段有较强数据一致性证据，但 PLC 点位表尚未确认信号定义。
3. **极端速度只能排除，不能还原。** 程序能阻止不可信速度和关联可疑原始贯入度进入分析，但不能凭给定速度恢复真实实际速度。
4. **约 20 秒采样存在时间分辨率上限。** 很短的空转、空推和快速升降可能只有零到少量样本，无法可靠单独识别。
5. **跨项目泛化尚未验证。** 当前冻结阈值只在这台 TBM 的这批数据和 10 天目视样本上检查，不能直接声称适用于其他设备、地层或采样系统。
6. **施工响应不能替代因果诊断。** 多参数共同变化可作为日报事实，但不能自动解释为地质恶化、刀具磨损、卡机或设备故障。
7. **参数工程单位尚未确认。** 工程语义完整 JSON 已保留统计值、变化量、比较基准和单位状态，但正文和 LLM 输入不会发布这些绝对值。
8. **重点响应仍需工程人员复核。** 91 天中有 2 天输出超过 8 条重点响应；这些事件通过当前持续性和多参数规则，但“关注价值”尚无人工标签可用于定量验证。
