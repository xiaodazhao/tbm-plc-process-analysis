# 第三章 方法 新版草稿

本章描述当前代码已经实现的三章日报候选流程。它与此前的“PLC前两章单独生成、地质第三章单独规划、最后确定性拼接”流程不同：PLC和地质资料先分别完成专业处理，再转成具有统一编号和来源的事实，汇入同一份日级JSON；大语言模型在读取这份联合输入后规划整份三章日报。旧流程保留作历史基线，不能把旧PDF的生成记录误写成新流程的实验结果。

## 3.1 总体框架与任务边界

研究对象是包含当日施工总体情况、主要施工过程和地质信息汇总的完整TBM施工日报。系统接收两路性质不同的证据：按时间采样的PLC记录，以及TSP、HSP超前预报和历史掌子面素描。两路数据分别处理，是因为机器参数需要按时间连续性和质量标记分析，而地质文字需要按形成日期、来源和适用里程筛选。分支处理完成后，以日期和导向盾首里程为共同索引，形成联合事实包，再进行全文内容规划、受约束写作及成品检查。

Python负责字段映射、质量控制、统计、运行区间、地质资料准入、空间关联、图表和确定性约束。大语言模型只负责选择和组织已提供的事实、撰写自然语言陈述；它不重新划分运行区间，不计算进尺，不绘制曲线，也不能补充未给出的地质结论。

## 3.2 PLC施工数据处理与过程事实提取

PLC分支沿用已有分析版本。原始日级CSV或Excel经字段别名映射形成统一字段，同时保存源文件和原始行号。预处理检查时间戳、采样硬缺口、导向盾首里程、速度异常、转速暂定映射和关键参数有效性；跨硬缺口的未知时间不计入工作或停机时长。运行平台由平滑后的推进速度、总推力、刀盘扭矩和刀盘转速提供多参数活动证据，再在平台内识别启动、上升、稳定和下降阶段。阶段缺失是允许的，不为凑齐四阶段而填补。阶段内提取稳健参数统计、持续趋势、波动及多参数共同变化，事件保留时间和原始记录范围。

日报事实构建使用冻结分析输出，不重算平台和阶段边界。日进尺取当日有效导向盾首里程的首末差；工作、停机和设备时间利用率沿用有数据支持的状态计时口径。全部算法平台进入确定性明细表，但不被直接称为经人工确认的真实掘进循环。区间进尺仅在既有质量规则允许时显示，取“开累进尺”首末差，不能替代日进尺。主要参数在明确统计范围和有效样本数量后报告；工程单位没有点位资料确认时保留“原始PLC记录值”的限定。

## 3.3 地质资料结构化与可用性筛选

地质分支沿用既有PDF提取及V2内容单元结果，主仓库当前不重新解析PDF。TSP和HSP记录的是在原报告中给出的前方预测，掌子面素描记录的是此前特定位置的观察或推测。内容单元保存资料类别、原始文件、页码、来源事实编号、日期依据、适用里程、预测分段、风险点或风险区间，以及原文证据和表达角色。

针对施工日D，联合入口只接受有可靠日期依据、且早于D日00:00的地质单元。若同一原始报告中的风险单元未重复写日期，可引用同一来源预报分段已经核实的报告日期，并记录日期继承方式；同一报告出现互相矛盾的可用日期则中止。导向盾首起止里程与地质候选包中的PLC上下文必须一致，否则不做拼接。无法确认时刻、里程或来源的资料不能由模型自行补足。

## 3.4 联合事实表示与跨源证据关系

系统把两路输出写入`integrated_facts.full.json`。每条事实具有唯一`fact_id`、事实类型、允许出现的章节、是否为规划必选项、内容数据及来源。PLC事实包括日进尺、状态时长、数据覆盖、总体参数、各运行平台和动态事件；地质事实包括预测分段、风险点/区间、历史素描或无可用资料说明。面向模型的`integrated_facts.llm_input.json`保留写作需要的内容及来源编号，完整证据仍留在全量包中。两类事实不是两份互不相关的提示词，而是在同一次全文规划请求中出现。

当某运行平台的导向盾首里程区间与某预报分段的适用里程区间相交时，程序可生成一个`cross_source_link`。该关系严格定义为“空间共位”，只保存两端事实编号和交集起止里程。它并不表示掌子面已经位于该区间，也不表示推力、扭矩或速度能够证实预报正确，更不是因果关系。由于导向盾首与掌子面的实际偏移尚未核实，现阶段不进行机器响应反证地质预报的工程判断；联合事实结构只是为将来单独设计并验证这类分析留下接口。

## 3.5 全文内容规划与受约束生成

模型先读取联合事实和空间链接，输出包含三章、段落意图、选用`fact_id`及必要`link_id`的JSON计划。规划器可选择具有代表性的PLC过程进入叙述，但所有平台仍保留在程序绘制的明细表；地质必选单元不得因压缩文字被静默丢弃。计划校验检查章节顺序、事实存在性、章节准入、地质3.1/3.2小节归属、跨源链接两端是否同时在段内，以及必选事实覆盖。计划有接口错误时，程序最多让模型依据错误列表定向修正一次；原始计划和修正记录均保存。

通过校验的计划连同选中事实进入正文生成。模型按段输出可单独检查的陈述，每条陈述标注支持它的事实编号和必要的空间链接。提示词禁止改写数值、将预测写成当日实际揭露、把历史素描外推到邻段，或把机器响应解释为地质、刀具或设备故障原因。程序对生成稿执行来源编号、数值、时间、里程、必选事实、预测/观察属性及部分因果表述检查。数值可按原始浮点数合理舍入，但不能凭空替换成其他数。未通过的生成稿保留原始响应并中止，不会用规则模板冒充模型输出。

## 3.6 报告组装、追溯与当前验证范围

第一章的日进尺、工作停机时间和利用率，第二章的全部运行平台表、时间轴和原始逐时刻参数曲线，以及第三章的TSP/HSP里程轴、风险符号、来源表，均由程序依据结构化数据生成。模型提供的三章叙述经转义后插入固定HTML版式，Chrome将HTML导出为PDF。输出保留完整联合事实、模型请求与原始响应、模型版本及Token、计划和正文校验、最终HTML/PDF与渲染检查，便于从陈述返回事实编号和原始材料。

确定性检查通过只能证明接口和可计算项目未发现违规，不证明每一句地质描述都得到原始PDF的完整语义支持。当前联合入口把自然语言陈述标为`REVIEW`；此前地质V2的LLM辅助语义审查和局部修正链尚未整体接入这个新入口，不能写成已在联合报告上运行。2024年1月6日的一次候选验证生成了完整三章PDF，并通过内部校验；这是一日接口验证，不是全329日准确率，也不是跨TBM泛化结论。正式论文中关于事实支持性、重要信息覆盖和方法优势的主张，仍需独立人工评价及预先固定的对照实验支持。
