# 多源证据图联合分析与日报：实际方法

版本：`tbm_evidence_graph_v1_20261027`。本组件是工程分析候选增量，不替代原冻结PLC方法。

## 1. 文献借鉴范围

核对了Huang等（2026）GeoMRF原论文及出版方页面：
https://doi.org/10.1016/j.tust.2026.107825

原文第3节将知识建模、图引导检索和受约束写作连接，用于不良地质处置推荐。本项目只借鉴“有时空属性的工程证据关系、检索、来源约束”的组织思想。本组件不复现其语义编码器、排序器、处置本体、训练数据或效果数字；不推荐措施。没有把SQLite、JSON或存在路径本身当作研究创新或有效性证据。

## 2. 源数据与两条处理线

PLC线复用修复后逐点结果、原平台与四阶段标签，以及V2已计算的PR/FPI/SE和真实时间窗口，不重新分段。只有与真实地质分段有对应意义的摘要进入图，日总进尺和全天时间仍由原日报事实独立提供。

地质线复用7份TSP、49份HSP结构化结果。素描严格替换为当前桌面伯舒拉岭数据中的244份原始结构化JSON，而不是叠加旧便携素描，防止同一内容双重使用。JSON中同时存在设计转述、原表施工分级、前方推测及此前开挖段落观察；按原字段和保守分句分别保存。没有明确分句里程的观察描述保留，但不扩展至表头整段。原图来自同目录本地JPG，核对SHA后原样复制，不从网络下载替代图。

244份JSON按字节SHA对应214份唯一内容，30份完全重复副本不重复建文档节点；全部路径与文件仍保留。内容不同的同里程资料不自动合并，也不选定某条为正确版本。

## 3. 节点与关系

| 节点 | 实际存储 |
|---|---|
| ConstructionSegment | 原资料区间/点、日施工盾首参照、前方窗口、PLC对照分段；保留几何类型、里程体系、方向和来源 |
| GeologyDocument | 来源类型、原文件/SHA、形成/可用/观测日期及精度、原始元数据、日期审计、本地图片索引 |
| GeologyFact | 单一字段或保守分句、值、信息性质、原文、属性、几何、PDF页码或JSON指针、提取及核对限制 |
| PLCResponse | 地质区间内质量合格的稳定推进摘要、实际时间、样本数/比例、窗口、基准、精确源行及计算口径 |
| EngineeringComparison | 源间属性差异、机器区段比较、预测与素描资料对照、历史描述对照；明确不是原始事实 |
| ReportClaim | 程序构造的候选文本、支持ID、范围、章节、选用/省略原因、实际写入状态 |

九种实际关系为HAS_FACT、COVERS、OBSERVED_AT、MEASURED_OVER、OVERLAPS_WITH、COMPARES、DIFFERS_FROM、DERIVED_FROM、SUPPORTED_BY。端点类型先检查，之后再核对成员、几何、属性是否真的相符。仅连上边但内容不成立会失败。

SQLite以节点、边、元数据保存；JSON是同内容的可复现快照。原始PLC记录不逐点入图，只保存精确来源索引。没有固定10m网格，也没有强因果边。

## 4. 时间政策及来源审计

查询日D的资料必须先过时间门禁。TSP/HSP读取正文提交日期、封面及检测日期来源页，核对PDF SHA和日期证据。仅有日期的既有资料采用既有保守前日政策，明确不等于独立核实了实际收件时刻。同日无核实具体可用时刻不作为此前施工的既有预测，未来资料不回填。

发现文件名与原PDF日期不一致时保存差异；只有独立原页日期证据相互支持时才能使用正文日期，不静默选择文件名或旧日报日期。元数据中未解决的正文日期冲突仍拒绝。日期核对不是人工提取准确率。

对于本批244份素描，依据用户2026-10-27的明确确认，将其图片URL路径日期作为报告可用日期。保存依据、候选日期和日精度；不补造具体时间，不把可用日期等同实际观察时刻。同日记录仍不用于解释未知可用时刻之前的运行。不同图片日期不一致会被隔离待核实。原JSON与JPG保持不变。

## 5. 区段响应与工程对照

复用V2的稳定标签、推进状态及信号质量交集；实际转速不可靠、非有限或负负载不进入性能计算。PR=v/n；FPI按PLC总推力/(70PR)计算，不能冒称净刀具法向力指标；SE统一SI后以MJ/m³表示，不等于电耗。公式与原V2一致，图组件不另立一套模型。

区间来自预报原边界和实际日范围的交集，按半开区间归属，日终点进入最后一段，原行号集合完整保存。先前可比区段必须在当前合格记录之前结束，并通过原V2转速/推力容差。缺少基准时只报统计；达到比较判据也只表示参数分布的描述性变化。

TSP/HSP比较等级和已记载的属性；一方未记载不是“没有该现象”。等级明确不同与文字不同待语义确认分开。素描与此前预测可作原资料属性对照，但本批可用日期不证明实际观察时刻，因此不输出预报准确率。源文件中的推测不能升格成观察。素描转述的设计分级不是独立设计文档。

盾首与掌子面偏移未知。所有地质—机器对照均标为名义位置相关；没有米级精确验证，没有地质致因判断。PR/FPI/SE共用变量，不当作三份独立地质证据。风险点与影响区间保持原义，跨日范围的风险陈述同时展示原范围和实际交集。

## 6. 查询及实际报告接通

A查询当日有效地质；B查询对应PLC与对照；C查询此前可用素描及单独的观察、推测、设计转述；D查询盾首参考前方20m及具体风险距离；E查询可进入报告的候选陈述。前方窗口依推进方向，未知方向不硬造。

从查询结果形成确定性ReportClaim。保留明确等级差异、风险及合格响应，重复等级统计由原表展示；同来源对、同等级的连续比较才合并，保留全部组成证据。不规定每天必须产生多少联合结论。

选中的图陈述真正进入writing_facts、内容计划和六章正文，最终PDF逐条核对包含这些文字。日总进尺、状态时间及普通运行明细仍来自原输入。本轮默认离线程序写作，实际API调用0次。保存未发送的完整规划/生成请求，供后续明确授权后调用既有接口；本轮没有证明真实LLM联合写作或规划增益。

当前原图在第四章展示，证据附录展示三条陈述的来源关系，完整查询、关系和追溯另存，不用图形替代检索。

## 7. 核验范围

自动核验端点类型、原文来源成员、空间交集、属性差异、基准先后、资料时间、候选支持ID、PDF包含性和旧源码SHA。错误关系、未来源、错误中文数值及无依据诊断有回归测试。

PROGRAM_SUPPORTED表示当前确定性文本在程序链路内有类型、来源和计算支持，不等于独立工程事实正确。修改过的文字如果出现新数值或诊断则FAIL，其他未证明语义为REVIEW；正确ID或路径不能使任意新句子自动通过。尚无专家标签、现场位置偏移标定或跨TBM外部验证。

## 8. 公平比较与后续实验

普通字段检索和图检索使用同一事实池、日期门禁、空间范围及属性。普通方法可以用ID和关系字段重建相同证据，不刻意削弱基线。当前比较记录集合交并及差异，不称为Recall或相关性准确率。

若两者返回相同资料，应如实报告。图的候选价值在于集中表达、校验和复用多来源支持关系；是否改善检索完整性、写作实用性或减少无依据结论，仍须独立标注、相同模型输入预算和真实对照实验。不得仅因有路径就得出方法优越结论。

## 9. 复现与限制

运行命令和参数见模块README。每次输出含真实来源校验、SQLite/JSON、A—E查询、基线对照、候选及省略、随机陈述核验、完整事实、原始行集合、图件、离线正文和PDF。快照不覆盖原始文件，不提交Git或推送。

尚未有独立核定设计分段的真实端到端案例；复杂地质语义仍需人工；实际观察时刻与报告可用日期未混同；空间映射仍未标定。这些是本版真实限制，不应包装成仅缺最终人工打分。
