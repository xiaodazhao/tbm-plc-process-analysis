# 压力测试解释

80项由8类、每类5个指定错误及其正确对照组成。它们来自真实输入的受控文字扰动，不是80个独立工程事件，也不是80份专家真值。

CSV中的sealed_test沿用了旧模板的拆分名称，不能解释成真正盲封、从未被开发者阅读的样例。模板已经被读取，本轮未根据结果修改冻结检查器。全部结果及漏检原文保留。

本轮TP=34、FP=0、FN=6、TN=40，仅表示指定扰动上的程序表现。6个漏检包括1个追加地质因果陈述，以及5个保留来源ID却删除实质信息的案例。正确样例未误拦不意味着自然生成文字没有误报；正式样本已另记录正确结构化时刻被canonical数字检查提示的反例。

因此这些数值不能写成实际日报事实准确率、故障识别准确率或自然幻觉检出率，也不能将REVIEW视为人工通过。
